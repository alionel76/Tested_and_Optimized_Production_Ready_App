# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-03-30
### Added
- Feature-First Architecture refactoring across all modules.
- Full Internationalization support for French (FR) and English (EN) using ARB templates.
- Theme management (System, Light, Dark mode) via `SettingsController`.
- Semantics and accessibility tags across all interactive UI widgets.
- Complete automated test suite (13 unit tests, 6 widget tests, 2 integration tests).
- GitHub Actions CI/CD workflow pipeline for automated analysis and tests.

## [0.2.0] - 2026-02-15
### Added
- Item repository with filtering, category selection, and real-time search.
- Interactive screens: `HomeScreen`, `ItemDetailScreen`, `SearchScreen`, and `AddItemScreen`.
- Form validation for adding new items with immediate feedback.

## [0.1.0] - 2026-01-10
### Added
- Initial Flutter application setup.
- Basic Material 3 theme configuration.
